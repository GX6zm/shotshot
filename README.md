# 60 秒塔防 · TOWER 60

双击 `index.html` 就能玩。零依赖、零素材文件、不用联网。

## 操作

| 输入 | 作用 |
| --- | --- |
| 移动鼠标 | 瞄准 —— 炮塔**自动开火**，不用点 |
| 空格 | 过载脉冲：清场 + 击退一圈敌人（有冷却） |
| 1 / 2 / 3 | 选强化 |
| P / ESC | 暂停 |
| F | 自瞄模式：炮塔自动锁定最靠近核心的敌人，带提前量 |
| M | 静音 |
| R | 结算界面再来一局 |

## 玩法

- 炮塔在场地正中央，怪物从四周传送门涌来，**每波 60 秒**。
- 撑满 60 秒 → 清场、回血、弹出**三选一强化**。
- 每 5 波降临一只 **BOSS**，血条挂在屏幕顶部。
- 核心装甲归零 = 结束。无尽模式，拼分数，最高分记在浏览器本地。

## 敌人

| 形状 | 类型 | 特点 |
| --- | --- | --- |
| 菱形 | 小兵 | 数量最多，成群涌来 |
| 三角 | 快兵 | 跑得飞快，血薄 |
| 方块 | 重装 | 慢、肉厚、撞一下很疼 |
| 六边形 | 分裂体 | 死后炸成两只小的 |
| 圆环 | BOSS | 血厚伤高，掉落大额分数 |

## 15 种强化（三档稀有度，可叠层）

- **常规（蓝）** 连射 · 高爆弹头 · 加速弹道 · 紧急维修 · 脉冲扩容
- **稀有（紫）** 多管齐射 · 穿甲弹 · 跳弹 · 冷冻弹 · 暴击 · 无人机 · 护盾
- **史诗（金）** 副炮台 · 爆裂弹 · 时间扭曲

## 打击感清单

- 命中定格（hitstop）、震屏、全屏色闪、击杀慢镜、缩放冲击
- 三层子弹拖尾、敌人受击白闪与击退、伤害飘字、连击计数
- 音效全部 WebAudio 实时合成（无音频文件），连击越高音调越高
- 每波开场环形突袭，BOSS 有专属入场演出

## 自瞄模式（按 `F`）

给不想手动瞄准、想纯看特效、或者想挂机看后期的人。

开启后炮塔自动锁定**离核心最近**的敌人（最急的那个），并按子弹飞行时间做提前量预判；HUD 左下角亮起 `● 自瞄 ON`，被锁定的敌人身上会套一圈琥珀色锁定环。再按一次 `F` 关闭，随时切回手动。没有目标时炮塔不开火，不会空放。

## 技术

单文件夹两个文件：`index.html` + `game.js`（原生 JS，Canvas 2D，约 1900 行）。
分辨率自适应窗口，无构建步骤、无第三方库。

## 开发脚本（`dev/`，不影响游戏）

```
node dev/dev-smoke.js       # 无头冒烟测试：48 条断言，跑完整游戏流程
node dev/dev-shot.js        # 无头 Chrome 截图（CDP），输出 shot-*.png
node dev/dev-balance.js 5   # 机器人跑 5 局，评估难度曲线
```
